Stonkz SMP is a zip with a ready-made `server` folder. It holds 28 plugin jars with their configs, the Stonkz Exchange spawn world and a small datapack. Paper itself is not included.

## Package layout

| Path | What it is |
| --- | --- |
| `server/plugins/` | All plugin jars and their configured folders |
| `server/world/dimensions/minecraft/spawn/` | The Stonkz Exchange spawn world (a void world) |
| `server/world/datapacks/stonkzsmp/` | Datapack that catches players who fall off the spawn island and puts them back |
| `server/commands.yml` | Adds the `/shop` and `/worth` shortcuts |
| `README-INSTALL.md` | The install guide |
| `THIRD-PARTY-LICENSES.md` | Licences and source links for the free plugins |
| `rebrand.bat`, `rebrand.ps1` | Puts your server name and address on the scoreboard, tab list and menu |

No licence keys ship in the zip. You claim your own in Discord. See [Licence keys](/stonkz-smp/licence-keys).

## What the setup adds on top

The plugins are only half of it. The setup also ships:

- **The Stonkz Exchange** spawn build, with NPCs, holograms, crates and the AFK Lounge already placed. See [Spawn](/stonkz-smp/spawn).
- **A tuned market.** Stonkz's balanced default prices, with items disabled where they would create an endless money loop.
- **Spawner prices and the Stonkz price link** in 3TSpawner, so spawner loot sells at the live market price.
- **An event calendar** in WorldEvents PRO, with no events at spawn.
- **A 30-day season** in SeasonManager PRIME, waiting in pre-season until you start it.
- **Four ranks** with prefixes and perks. See [Ranks](/stonkz-smp/ranks).
- **Scoreboard, tab list, chat format and `/menu`**, styled to match.
