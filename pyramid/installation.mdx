## Requirements

- **Java**: Java 21 for 1.21.x; Java 25 for Paper 26.1+.
- **Server**: Paper or Purpur **1.21.4 or newer**, within the release's listed versions. The released build does not support 1.20.x or 1.21.0–1.21.3. Folia support is partial; test the economy and player actions on your exact build before using it.
- **Vault**: The standard economy API.
- **Economy Plugin**: Any Vault-compatible economy plugin (EssentialsX, etc.).

## Installation Steps

1.  Download `Pyramid.jar`.
2.  Drop it into your `/plugins` folder.
3.  Restart your server.
4.  Configure `config.yml` to your liking.
5.  (Optional) Install [Stonkz](https://mbaconz.gitbook.io/stonkz) for advanced features.

## Updates and support

Keep your existing configuration and data when replacing the JAR. Follow [Updating and getting help](/maintenance) for backups, restart checks and the details to include in a support ticket.
