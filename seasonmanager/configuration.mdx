Edit your edition's generated `config.yml`: `plugins/SeasonManager/` for Core or `plugins/SeasonManager-Prime/` for PRIME. The example below is a subset of the settings, not a replacement for the entire file. Keep your licence and existing settings, and merge keys into the existing sections.

```yaml
# ══════════════════════════════════════════════════════════════════════════════
# SeasonManager - Main Configuration
# ══════════════════════════════════════════════════════════════════════════════

# ─────────────────────────────────────────────────────────────────────────────
# Season Settings
# ─────────────────────────────────────────────────────────────────────────────
season:
  # Current season number available for flexible increments (e.g. 1.0, 1.1)
  current-number: 1.0
  
  # Amount to increment season by when advancing (e.g. 1.0, 0.1)
  increment: 1.0
  
  # Current state: PRE_SEASON, ACTIVE, or POST_SEASON
  state: PRE_SEASON
  
  # Default season duration (e.g., 7d = 7 days, 12h = 12 hours)
  duration: 30d
  
  # Automatically end season when timer reaches zero
  auto-end: true

# ─────────────────────────────────────────────────────────────────────────────
# BossBar Settings
# ─────────────────────────────────────────────────────────────────────────────
bossbar:
  timer:
    enabled: true
    text: "<gradient:#00FFFF:#00AAAA><bold>⌛ SEASON TIMER</bold></gradient> <gray>»</gray> <gold>%time%</gold> <gray>remaining</gray>"
    color: YELLOW
    style: PROGRESS

# ─────────────────────────────────────────────────────────────────────────────
# World Settings
# ─────────────────────────────────────────────────────────────────────────────
world:
  # Worlds to manage (empty = all worlds)
  managed-worlds: []
  
  # Archive folder for world backups (relative to server root)
  archive-folder: "season-archives"

# ─────────────────────────────────────────────────────────────────────────────
# Notifications
# ─────────────────────────────────────────────────────────────────────────────
notifications:
  warning-times:
    - 60    # 1 hour
    - 30    # 30 minutes
    - 10    # 10 minutes
    - 5     # 5 minutes
    - 1     # 1 minute

# ─────────────────────────────────────────────────────────────────────────────
# Player Join Settings
# ─────────────────────────────────────────────────────────────────────────────
on-join:
  show-title: true
  show-bossbars: true
  delay-ticks: 20
```

## Explanation

*   **season.current-number**: Tracks the iteration of your season.
*   **season.duration**: Supports standard time formats (d, h, m, s).
*   **world.managed-worlds**: If left empty `[]`, all worlds on the server will be included in archival/reset processes.
*   **notifications.warning-times**: Add or remove integers to configure when chat/title warnings appear before the season ends.

## Grace period

Add these keys inside your existing `season:` section:

```yaml
season:
  grace-period: 1h
  grace-period-pvp: true
  grace-period-damage: false
  clear-inventory-on-start: false
```

`grace-period-pvp: true` disables PvP during grace. `grace-period-damage: true` also blocks other player damage. Keep `clear-inventory-on-start: false` unless you deliberately want a season start to empty player inventories.

Run `/season reload` after supported config edits. Use `/season info` and `/season grace status` to inspect the result. Set the remaining time of an already active season with `/season settime`, rather than editing runtime state fields.

## PRIME data and displays

PRIME uses additional files for its timeline, Discord and storage features. Keep those files and its data directory when updating. Review `world.managed-worlds` before enabling archives or reset actions; an empty list targets all worlds.

The released `tab:` and `scoreboard:` sections are inactive. Use the bossbar, or the [placeholders](/seasonmanager/placeholders) in your own tab/scoreboard plugin.
