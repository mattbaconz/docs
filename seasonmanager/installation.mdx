## Requirements

- **Server:** Paper or Purpur. Core 1.0.1 is listed for 1.21.11; PRIME 1.1.3 is listed for 1.21.11 and 26.1. Use the compatibility list on the version you download.
- **Java:** the version required by your server: Java 21 for these 1.21.x builds, Java 25 for 26.1.
- **PRIME:** a SeasonManager PRIME licence key and outbound access for activation.
- **Optional:** PlaceholderAPI for placeholders in another plugin; Vault and an economy provider for money rewards.

Folia and plain Spigot are not supported by these releases. A `folia-supported` declaration in an older JAR does not make its season, world and archive operations safe on Folia.

## Install

1. Download Core from [Modrinth](https://modrinth.com/plugin/seasonmanager) or PRIME from [BuiltByBit](https://builtbybit.com/resources/88221/).
2. Stop the server and back up existing SeasonManager data and worlds.
3. Put one edition in `plugins/`. Remove the previous edition's JAR if you are switching editions.
4. Start once to generate the files, then stop before editing them. Core uses `plugins/SeasonManager/`; PRIME uses `plugins/SeasonManager-Prime/`.
5. For PRIME, put your purchased key in the top-level `license_key` field of its `config.yml` and restart. Core does not require a paid key.
6. Set `season.duration` and the grace rules in [Configuration](/seasonmanager/configuration).
7. Run `/season info`, then `/season start` when you are ready to begin. Check the bossbar and grace behavior with a player.

Use `/season reload` for supported config changes. Replacing a JAR needs a full restart. `/season next` advances the season and can run archive/reset actions; it is not an installation test.

PRIME players use `/stash` (alias `/vault`) with permission `seasonmanager.stash`. Keep the PRIME data folder when updating so stored items survive.

## Updates and support

Keep your existing configuration and data when replacing the JAR. Follow [Updating and getting help](/maintenance) for backups, restart checks and the details to include in a support ticket.
