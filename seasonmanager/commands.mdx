---
title: 'Commands and permissions'
description: 'Season controls, PRIME stash access and administrative permissions.'
---

`/season help` shows the commands available in your installed edition. Core is the free edition, called Lite in some older messages.

## Season controls

| Command | Purpose | Permission |
| --- | --- | --- |
| `/season info` or `/season status` | Show the current season and timer | `seasonmanager.use` |
| `/season help` | Show help | `seasonmanager.use` |
| `/season start` | Start the season | `seasonmanager.admin` |
| `/season stop` | Stop the season | `seasonmanager.admin` |
| `/season next` | Advance to the next season; PRIME can archive/reset worlds | `seasonmanager.admin` |
| `/season settime 2d` | Set remaining time on an active season | `seasonmanager.admin` |
| `/season grace on` | Force grace on for the active season | `seasonmanager.admin` |
| `/season grace off` | Force grace off | `seasonmanager.admin` |
| `/season grace auto` | Return grace to the configured timer | `seasonmanager.admin` |
| `/season grace status` | Inspect the grace override | `seasonmanager.admin` |
| `/season reload` | Reload supported configuration | `seasonmanager.admin` |

`settime` and `reload` are available in Core as well as PRIME. Use durations such as `10m`, `1h` or `2d` with `settime`.

## PRIME commands

| Command | Purpose | Permission |
| --- | --- | --- |
| `/stash` | Open your cross-season stash; `/vault` is an alias | `seasonmanager.stash` |
| `/leaderboard top` | View rankings | `seasonmanager.leaderboard.top` |
| `/leaderboard create` | Create a leaderboard hologram | `seasonmanager.leaderboard.create` |
| `/leaderboard remove` | Remove a leaderboard hologram | `seasonmanager.leaderboard.remove` |
| `/leaderboard list` | List holograms | `seasonmanager.leaderboard.list` |
| `/leaderboard update` | Refresh holograms | `seasonmanager.leaderboard.update` |
| `/season backup pre-war` | Create a named world archive | `seasonmanager.admin` |
| `/seasonrollback list` | List available rollback backups | `seasonmanager.admin.rollback` |

Use command help for the required arguments before changing a hologram or restoring an archive. Holograms require DecentHolograms and are affected by a startup integration issue in the current release; do not rely on them as your only season display.

`seasonmanager.use`, `seasonmanager.stash` and `seasonmanager.leaderboard.top` default to players. Administrative permissions default to operators. The old `seasonmanager.vault` node is not the stash permission.

Before `/season next` or a rollback, back up worlds and plugin data and test your transition settings on a copy of the server.
