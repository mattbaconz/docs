Core is the free edition; older documentation calls it Lite. PRIME includes the season controls and adds storage, automation and integrations.

| Feature | Core | PRIME |
| --- | --- | --- |
| Season timer, start/stop/next | Yes | Yes |
| Bossbar and title notifications | Yes | Yes |
| Grace controls, settime and reload | Yes | Yes |
| PlaceholderAPI season display | Yes | Yes |
| Cross-season `/stash` | No | Yes |
| World archives | No | Yes |
| Scheduled actions in `events.yml` | No | Yes |
| Discord integration and web dashboard | No | Yes |

## Cross-season stash

PRIME stores a player's stash outside the world. `/stash` opens it; `/vault` is an alias. The permission is `seasonmanager.stash`. Back up the PRIME data folder as well as the world before a reset or upgrade.

## Season transitions

Set the duration and grace rules, then start the season with `/season start`. PRIME can run timeline actions, phase changes and archive operations. Configure the intended worlds before advancing a season. A timer reaching zero, stopping a season and advancing to the next season are different actions; check your configured end commands and archive/reset behavior on a copy first.

## Displays and platform limits

Use the bossbar or [PlaceholderAPI](/seasonmanager/placeholders) with a separate tab/scoreboard plugin. The released plugin's `tab:` and `scoreboard:` config sections do not create those displays. Hologram integration also has a startup limitation in the current release.

Use Paper or Purpur for the released editions. Folia support is not available for the full season/world lifecycle.
