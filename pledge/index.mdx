**Pledge** turns store activity into visible server progress. It connects community goals, supporter boards, global rewards, sale countdowns, Discord alerts, and provider events into one configurable plugin.

![Pledge infographic showing goals, supporter boards, store flow, Discord alerts, PlaceholderAPI support, and admin tools](/images/pledge-infographic.png)

## What Pledge does

- **Community goals** track store progress with GUI displays and optional bossbars.
- **Supporter boards** show recent supporters and daily, weekly, monthly, and yearly top supporters.
- **Smart store flow** accepts Tebex, CraftingStore, and manual purchase events.
- **Global rewards** run broadcasts and configured commands when goals complete.
- **Sale tools** manage sale countdowns, status, and announcements.
- **Discord alerts** send purchase, progress, and completion updates.

## Compatibility

Pledge supports **Paper/Folia 1.20.6-26.x.x** and requires **Java 21+**.

<Note>
Paid builds require a Pledge license key in `config.yml`. The license product id is `PLEDGE`.
</Note>

## Quick commands

```text
/goals
/support
/pledge status
/pledge admin
/pledge top weekly
```
