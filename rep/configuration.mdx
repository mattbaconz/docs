---

Rep stores settings in `plugins/Rep/config.yml`. Messages are in `messages.yml`; translations live in `lang/`. Reload both with `/rep reload`.

For rank tier logic and threshold examples, see [Ranks & thresholds](/rep/ranks).

## General

```yaml title="general"
general:
  default-score: 0
  debug: false
  prevent-self-rep: true
  allow-offline-rep: false
  leaderboard-size: 10
  use-chat-prefix: false
  use-tab-prefix: false
```

| Key | Description |
| --- | --- |
| `default-score` | Starting reputation for new players and `/rep reset` |
| `debug` | Extra console logging |
| `prevent-self-rep` | Block giving rep to yourself |
| `allow-offline-rep` | Allow player commands to target offline players |
| `leaderboard-size` | Players shown in `/rep top` |
| `use-chat-prefix` | Show rank prefix after player name in chat |
| `use-tab-prefix` | Show rank prefix in the tab list |

## Cooldowns

```yaml title="cooldowns"
cooldowns:
  global-command-cooldown: 60
  player-specific-cooldown: 3600
  max-rep-per-day: 0
```

All values are in seconds. `max-rep-per-day: 0` means unlimited.

## Reputation amounts

```yaml title="reputation-amounts"
reputation-amounts:
  plus: 1
  minus: -1
```

Used by `/rep <player> plus` and `/rep <player> minus`.

## Ranks

Define rank tiers under `ranks`. Each entry needs `name`, `score-threshold`, and `chat-prefix`.

See [Ranks & thresholds](/rep/ranks) for assignment rules and worked examples.

## Event changes

Automatic rep from player actions. Set any key to `0` to disable.

```yaml title="event-changes"
event-changes:
  player-kill: -5
  villager-kill: -10
  iron-golem-kill: -15
  attack-tamed-animal: -3
  attack-villager: -5
  attack-iron-golem: -5
  tame-animal: 2
  breed-animal: 1
  villager-trade: 1
  cure-zombie-villager: 20
```

## Mob changes

Per-entity rep on hit or kill. Use Paper `EntityType` names.

```yaml title="mob-changes"
mob-changes:
  hit-default: 0
  kill-default: 0
  hit-cooldown-seconds: 1
  hit:
    ZOMBIE: 0
  kill:
    CREEPER: 5
    ENDER_DRAGON: 200
```

## World restrictions

```yaml title="world-restrictions"
world-restrictions:
  mode: blacklist
  worlds:
    - example_world_name
```

- `blacklist` — rep is disabled in listed worlds (default behavior)
- `whitelist` — rep only works in listed worlds

The legacy `disabled-worlds` list is used only when `world-restrictions` is missing from config.

## Sounds

```yaml title="sounds"
sounds:
  enabled: true
  receive-plus: ENTITY_EXPERIENCE_ORB_PICKUP
  receive-minus: ENTITY_VILLAGER_NO
  rank-up: ENTITY_PLAYER_LEVELUP
  rank-down: BLOCK_ANVIL_LAND
  volume: 1.0
  pitch: 1.0
```

Set any sound to `none` to disable that effect. Use valid Bukkit `Sound` enum names.

## Particles

```yaml title="particles"
particles:
  enabled: true

  receive-minus: VILLAGER_ANGRY
  rank-up: TOTEM_OF_UNDYING

```

Set any particle to `none` to disable. Use valid Bukkit `Particle` enum names.

## Rank rewards

```yaml title="rank-rewards"
rank-rewards:
  enabled: true
  broadcast-rankup: true
  broadcast-rankdown: true
  commands:
    known:
      - "give {player} diamond 1"
  rankdown-commands:
    stranger: []
```

Commands run as console. Placeholders: `{player}`, `{uuid}`.

## Placeholders

```yaml title="placeholders"
placeholders:

    min-value: 1000
```

## Pro settings

Rep Pro features are configured under `pro-settings`. They require a valid `REP_PRO` license key — see [Rep Pro](/rep/pro) for claiming and activation.

```yaml title="pro-settings"
pro-settings:
  license-key: ""
  drm:
    enabled: true
  redis-sync: false
  redis:
    host: localhost
    port: 6379
    password: ""
  seasons-enabled: false
  seasons:
    auto-start: true
    duration-days: 30
    on-end: wipe   # wipe | carry-over
    carry-over-percent: 0
    start-score: 0
    discord-webhook: ""
  web-dashboard-enabled: false
  web-dashboard:
    bind: 127.0.0.1
    port: 8765
    token: ""
    allow-writes: false
  trust:
    evidence-enabled: true
    evidence-history-limit: 50
    anti-farm-enabled: true
    reciprocal-block-seconds: 86400
    unique-receivers-per-hour: 5
    trust-tiers-enabled: true
```

### License key

| Key | Description |
| --- | --- |
| `license-key` | Your `REP_PRO` license key. Claim via [Discord](https://discord.com/invite/VQjTVKjs46) after purchase. |
| `drm.enabled` | `true` (production) verifies the key online. `false` unlocks Pro locally — PlugDev / BBB demo only. |

### Trust (evidence / anti-farm / tiers)

| Key | Description |
| --- | --- |
| `trust.evidence-enabled` | Append +/- rows for `/rep history` |
| `trust.evidence-history-limit` | Max evidence rows (default 50) |
| `trust.anti-farm-enabled` | Reciprocal block + unique hourly cap |
| `trust.reciprocal-block-seconds` | Window where A cannot +rep B after B +repped A (default 86400) |
| `trust.unique-receivers-per-hour` | Max distinct +rep targets per hour (default 5; `0` = unlimited) |
| `trust.trust-tiers-enabled` | Score-band tiers with `on-enter-commands` |

See [Pro evidence](/rep/pro-evidence), [Pro anti-farm](/rep/pro-anti-farm), and [Pro trust tiers](/rep/pro-trust-tiers).

### Redis sync

| Key | Description |
| --- | --- |
| `redis-sync` | Enable cross-server cache invalidation via Redis pub/sub. Requires shared MySQL on all backends. |
| `redis.host` | Redis server hostname |
| `redis.port` | Redis server port (default `6379`) |
| `redis.password` | Redis password, or empty string if none |

See [Pro Redis sync](/rep/pro-redis) for architecture and setup.

### Seasons

| Key | Description |
| --- | --- |
| `seasons-enabled` | Enable reputation seasons |
| `seasons.auto-start` | Start the first season automatically on server boot |
| `seasons.duration-days` | Length of each season in days |
| `seasons.on-end` | What happens when a season ends: `wipe` (reset scores) or `carry-over` (keep a percentage) |
| `seasons.carry-over-percent` | Percentage of score kept when `on-end` is `carry-over` (0–100) |
| `seasons.start-score` | Starting score for players after a wipe or carry-over |
| `seasons.discord-webhook` | Discord webhook URL for season-end announcements |

See [Pro seasons](/rep/pro-seasons) for lifecycle, commands, and placeholders.

### Web dashboard

| Key | Description |
| --- | --- |
| `web-dashboard-enabled` | Start the built-in HTTP dashboard |
| `web-dashboard.bind` | IP address to bind (default `127.0.0.1` — keep local unless you add a reverse proxy) |
| `web-dashboard.port` | HTTP port (default `8765`) |
| `web-dashboard.token` | Bearer token required in the `Authorization` header |
| `web-dashboard.allow-writes` | Allow score mutations via the API (default `false`) |

See [Pro web dashboard](/rep/pro-dashboard) for pages and security notes.
